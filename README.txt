ГОТОВЫЙ ПОДАРОК — НАШ САЙТ
==========================

Что менять:
1. Открой config/config.js.
2. Поставь свою дату в startDate.
3. Поставь дату годовщины в anniversaryDate.
4. Замени список phrases на ваши фразы.
5. Положи фотографии в images и укажи их имена в images.
6. Положи MP4 в videos и укажи их имена в videos.
7. Положи музыку в audio/music.mp3.

Сайт работает без React, npm, сборщика и сервера.

Для публикации загрузи всю папку на GitHub Pages, Netlify или другой статический хостинг.

Музыка специально запускается по клику, потому что современные браузеры блокируют автозапуск звука.

SVG-файлы photo-01.svg ... photo-08.svg — рабочие заглушки.
Замени их своими фотографиями или измени пути в config.js.
